# 横瀬町における地域エネルギー資源の可視化と防災型マイクログリッド実現可能性の検討

青山学院大学 地球社会共生学部 古橋研究室  
2026年度 卒業論文 / 構想発表  
佐藤亜紀

## 概要

本研究では、埼玉県横瀬町を対象に、太陽光発電設備、蓄電池、太陽熱、EV/V2H、小水力候補、公共施設、避難所などを地図上で可視化し、それらが災害時に地域で使えるエネルギー資源になり得るかを評価する。

これまで作成した「横瀬町コミュニティ・ソーラーパネル台帳 / 発電量簡易推計」では、OpenStreetMapに登録された太陽光設備を抽出し、面積、推計容量、年間想定発電量を可視化した。しかし、太陽光パネルが存在することと、その電気を地域が必要なときに使えることは同じではない。蓄電池の有無、停電時の自立運転、売電契約、所有者の協力意思、避難所や公共施設との位置関係などを確認しなければ、地域資源として評価することは難しい。

そこで本研究では、発電量だけでなく「地域利用可能性」に着目し、横瀬町における防災型地域エネルギー拠点の候補を抽出するWebアプリケーションを制作する。

## 背景

近年、災害時の停電対策や脱炭素化の観点から、地域内の再生可能エネルギーや分散型電源を活用するマイクログリッドへの関心が高まっている。特に山間地域では、停電、道路寸断、孤立、避難所運営などのリスクを考慮し、地域内で最低限の電力・熱・通信環境を維持する仕組みが重要になる。

横瀬町にも太陽光発電設備は存在するが、それらが災害時に地域で利用できるかどうかは明らかではない。たとえば、太陽光パネルがあっても蓄電池がなければ夜間や悪天候時の利用は難しい。また、FIT売電、PPA、リース、屋根貸しなどの契約形態によっては、発電した電気を所有者や地域が自由に使えない可能性がある。

そのため、マイクログリッドの実現可能性を考えるには、単に発電設備の位置や発電量を調べるだけでは不十分である。設備の所有、契約、自立運転、蓄電、熱利用、公共性、防災上の安全性を含めて整理する必要がある。

## 目的

本研究の目的は、横瀬町内に存在する分散型エネルギー資源を「地域で使える資源」として再評価し、防災型マイクログリッドまたは地域エネルギー拠点の候補地を可視化することである。

具体的には、以下を目的とする。

- 横瀬町内の太陽光発電設備、公共施設、避難所などを地図上で整理する
- 太陽光設備を発電量だけでなく、地域利用可能性の観点から評価する
- 蓄電池、太陽熱、EV/V2H、小水力、木質資源など、太陽光以外の地域エネルギー資源も調査対象に含める
- 防災時に優先して守るべき施設や生活機能を整理する
- Webアプリとして、誰でも閲覧できる地域エネルギー資源マップを制作する

## リサーチクエスチョン

横瀬町に存在する太陽光発電設備やその他の分散型エネルギー資源は、災害時に地域の生活機能を支える資源として利用可能なのか。

補助的な問いは以下の通りである。

- 太陽光発電設備は、蓄電池や自立運転機能を備えているか
- 設備の所有形態や売電契約は、地域利用を妨げる要因になっているか
- 避難所、公共施設、福祉施設、通信拠点の近くに利用可能なエネルギー資源は存在するか
- 太陽熱、EV/V2H、小水力、木質資源などを含めることで、電力だけではない地域エネルギー拠点を検討できるか
- Web地図によって、地域住民や行政が調査・合意形成しやすい状態を作れるか

## 方法

本研究では、Webアプリ制作と空間データ分析を組み合わせて調査を行う。

### 1. 既存データの収集

OpenStreetMap、横瀬町の公開資料、埼玉県の防災情報、国土数値情報などを用いて、以下のデータを収集する。

- 太陽光発電設備
- 横瀬町行政界
- 避難所・避難場所
- 公共施設
- 学校・福祉施設
- 河川・水路
- 土砂災害・浸水などのハザード情報

### 2. Overpass APIによる太陽光設備の抽出

OpenStreetMapのOverpass APIを用いて、横瀬町周辺の太陽光設備を検索する。主な検索対象タグは以下である。

```overpass
way["power"="generator"]["generator:source"="solar"];
way["power"="plant"]["plant:source"="solar"];
way["building"="solar_panels"];
way["landuse"="solar_panel"];
relation["power"="plant"]["plant:source"="solar"];
relation["power"="generator"]["generator:source"="solar"];
```

取得したポリゴンから面積を算出し、簡易的に設備容量と年間想定発電量を推計する。

### 3. 地域利用可能性の評価

各エネルギー資源を、以下の5軸で評価する。

| 評価軸 | 内容 |
| --- | --- |
| 供給力 | 発電量、蓄電容量、熱供給量など |
| 自立性 | 停電時に単独で利用できるか |
| 公共性 | 避難所、公共施設、福祉施設、通信拠点などに近いか |
| 利用可能性 | 所有、契約、協定、地域協力意思の観点から使えるか |
| 安全性 | 土砂災害、浸水、孤立、道路寸断などのリスクが低いか |

評価結果は、以下のように分類する。

| 判定 | 意味 |
| --- | --- |
| A | すぐ地域資源化できる可能性が高い |
| B | 協定・運用設計があれば使える |
| C | 設備追加や詳細調査が必要 |
| D | 現状では地域利用が難しい |
| ? | 情報不足 |

### 4. 追加調査

OpenStreetMapや公開資料だけでは、蓄電池、契約、自立運転、地域協力意思などは把握できない。そのため、必要に応じて以下の調査を行う。

- 施設管理者へのヒアリング
- 住民・事業者向けアンケート
- 現地確認
- 町役場・地域団体への聞き取り

確認したい項目は以下である。

- 太陽光発電設備の有無
- 蓄電池の有無と容量
- 停電時の自立運転可否
- V2H・EV外部給電の有無
- 太陽熱温水器、薪ストーブ、ボイラーなどの熱資源
- 災害時に近隣住民へ充電・給湯・暖房支援が可能か
- 地図上での公開可否

### 5. Webアプリケーション制作

成果物として、GitHub Pagesで閲覧可能なWebアプリケーションを制作する。主な機能は以下である。

- 横瀬町の地図表示
- 太陽光設備のOverpass API検索
- 面積、推計容量、年間想定発電量の表示
- 避難所・公共施設・エネルギー資源候補のレイヤー表示
- 地域利用可能性のA/B/C/D評価
- データ確度と次に確認すべき項目の表示
- CSV / GeoJSON出力

## 期待される成果

本研究により、横瀬町内に存在するエネルギー資源を、単なる発電設備ではなく「地域で使える可能性がある資源」として整理できる。

期待される成果は以下である。

- 横瀬町地域エネルギー資源マップ
- 太陽光設備の発電量・地域利用可能性の一覧
- 避難所・公共施設との位置関係の可視化
- 追加調査が必要な項目の整理
- 防災型地域エネルギー拠点の候補エリア提案
- マイクログリッド実現に向けた初期調査手法の提案

## 構想発表時点のプロトタイプ

構想発表時点では、以下のプロトタイプを作成している。

- 横瀬町コミュニティ・ソーラーパネル台帳
- 太陽光発電量簡易推計Webアプリ
- 地域エネルギー資源マップの試作
- 太陽光設備の地域利用可能性評価機能

プロトタイプでは、OpenStreetMapの太陽光設備を取得し、面積、推計容量、年間想定発電量を算出する。また、選択した太陽光設備に対して、蓄電池、自立運転、契約、所有者協力、避難所との距離など、次に確認すべき調査項目を提示する。
