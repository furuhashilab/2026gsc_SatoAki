## Introduction

本研究は、埼玉県横瀬町を対象に、OpenStreetMapを地域エネルギー資源のデータベースとして活用し、太陽光パネル、蓄電池、送電線、変電所などの位置関係を可視化するWeb GISを構築するものである。

横瀬町では、脱炭素化や再生可能エネルギー導入に向けた政策が進められている。一方で、太陽光パネルが地域に存在していても、それが災害時に地域で使える電源になるとは限らない。蓄電池の有無、停電時の自立運転、売電契約、PPA、リース、屋根貸し、所有者の協力意思、プライバシー保護など、多くの条件が地域利用のハードルになる。

特に横瀬町のような山間部では、災害時に道路や通信、電力供給が外部から遮断されるリスクがある。そのため、地域内に既に存在する太陽光パネルや電力インフラを、単なる発電設備ではなく、非常時の地域資源として再定義する必要がある。

本研究の意義は、OpenStreetMapを単なる背景地図としてではなく、地域資源を記録・更新・共有するためのデータベースとして使う点にある。私はドローン部で活動してきた経験から、地域を観察し、空間情報として記録し、データベースを使って可視化・更新していくことに関心がある。本研究では、その経験を活かし、横瀬町のエネルギー資源を継続的に調査・編集・活用できる基礎地図を作成する。

### Research Question

横瀬町に存在する太陽光パネルや電力インフラは、山間部の災害時リスクに対応する地域資源として、どのように把握・記録・可視化できるのか。

補助的な問いは以下の通りである。

- OpenStreetMapを、地域エネルギー資源のデータベースとしてどこまで利用できるか
- 横瀬町内の太陽光パネル、蓄電池、送電線、変電所はどのように分布しているか
- 太陽光パネルの面積、推計容量、年間想定発電量をWeb地図上でどのように集計できるか
- OSMだけでは取得できない蓄電池容量、売電契約、自立運転、所有者同意、プライバシー情報をどのように追加調査すべきか
- 将来的に、防災型マイクログリッドやオフグリッド連携を検討するために、どのようなデータ項目が必要か

## Methods

本研究では、Webアプリ制作、OpenStreetMapデータ取得、空間解析、追加調査項目の設計を組み合わせる。

### 1. OpenStreetMapをデータベースとして利用する

OpenStreetMapは、道路や建物だけでなく、発電設備、送電線、変電所などの電力インフラもタグとして記録できる。本研究では、Overpass APIを用いて、OSMに既に登録されている地物を取得する。

太陽光設備は、主に以下のタグで検索する。

```overpass
way["power"="generator"]["generator:source"="solar"];
way["power"="plant"]["plant:source"="solar"];
way["building"="solar_panels"];
way["landuse"="solar_panel"];
relation["power"="plant"]["plant:source"="solar"];
relation["power"="generator"]["generator:source"="solar"];
```

電力インフラは、以下のタグで検索する。

```overpass
node["power"="storage"];
way["power"="storage"];
relation["power"="storage"];
node["generator:method"="battery"];
way["generator:method"="battery"];
relation["generator:method"="battery"];
node["battery"];
way["battery"];
way["power"="line"];
way["power"="minor_line"];
way["power"="cable"];
node["power"="substation"];
way["power"="substation"];
relation["power"="substation"];
```

これらは候補地として新たに推定するのではなく、OSMに既に登録されている既存情報のみを表示する。

### 2. 太陽光パネルの面積・発電量を簡易推計する

取得した太陽光パネルのポリゴンに対して、Turf.jsを用いて面積を計算する。面積から簡易的に設備容量と年間想定発電量を推計し、地図上のポップアップ、一覧表、ランキングに表示する。

現時点の推計は、設備仕様、方位、傾斜、影、劣化、稼働状況などを反映していない。したがって、行政判断や設備診断ではなく、基礎調査用の概算として扱う。

### 3. レイヤーとして独立表示する

Webアプリでは、以下のレイヤーを独立して表示・非表示できるようにする。

- 太陽光パネル
- 蓄電池
- 送電線・配電線
- 変電所
- OAM空撮画像

太陽光パネルは推計容量に応じて段階色で表示する。送電線、蓄電池、変電所はOSMタグの種類に応じて色分けする。

### 4. 今後必要な追加調査項目を整理する

OpenStreetMapだけでは、地域利用可能性の判断に必要な情報は取得できない。そのため、今後は以下の項目を追加調査する。

- 蓄電池の有無と容量
- 停電時の自立運転可否
- 売電契約、PPA、リース、屋根貸し等の契約形態
- 災害時に地域利用へ協力できるか
- 公開可能な位置情報の粒度
- 避難所、公共施設、福祉施設、通信拠点との距離
- 太陽熱、EV/V2H、小水力、木質資源など、電力以外の地域エネルギー資源

## Results

構想発表時点では、以下のWebアプリを作成した。

- [横瀬町地域エネルギー資源マップ](https://furuhashilab.github.io/2026gsc_SatoAki/)

現在の実装内容は以下である。

- MapLibre GL JSによる地図表示
- Overpass APIによるOSMデータ取得
- 太陽光パネルのOSMポリゴン取得
- 太陽光パネルの面積、推計容量、年間想定発電量、ピーク出力の簡易計算
- 太陽光パネルの単一選択と多角形範囲選択
- 面積、発電量、容量、ピーク出力ランキング
- CSV / GeoJSON出力
- OAM空撮画像の重ね表示
- Esri World Imagery、国土地理院陰影起伏図、CARTOの背景地図切り替え
- OSM上の蓄電池、送電線、変電所の取得
- 太陽光、蓄電池、送電線、変電所の独立表示切り替え
- オブジェクト種別・容量に応じた色分け表示

前回の太陽光パネル台帳からの発展は、太陽光パネル単体の可視化から、送電線、変電所、蓄電池を含む電力インフラの基礎地図へ拡張した点である。一方で、地域利用可能性のA/B/C/D判定は、裏付けデータが不足しているため削除した。

## Discussion

本研究の現時点での成果は、横瀬町に存在する太陽光パネルと電力インフラを、OSMを使って一覧・地図化できるようにしたことである。これにより、地域にどのような発電設備と系統設備が存在しているかを、誰でもWeb上で確認できる。

ただし、現時点のアプリで分かるのは、OSMに登録されている地物の位置、形状、タグ、および太陽光ポリゴンから計算した面積・発電量の概算である。蓄電池が実際にどれだけの容量を持つか、停電時に自立運転できるか、売電契約により地域利用が制限されるか、個人宅の設備情報をどこまで公開できるかは分からない。

したがって、本研究は「マイクログリッド実現可能性を判定するアプリ」ではなく、その前段階としての「地域エネルギー資源を調査・記録するためのOSMベースの基礎地図」である。今後は、OSMに記録されていない情報を、現地調査、住民・施設管理者へのヒアリング、公開資料の整理によって補完する必要がある。

横瀬町が再エネ政策を進めるうえで、蓄電池の導入、災害時のオフグリッド連携、売電契約の整理、プライバシー保護を同時に考える必要がある。本研究では、その議論の出発点として、太陽光パネルを「売電のための設備」だけでなく、山間部の遮断リスクに対応する地域資源として再定義することを目指す。
